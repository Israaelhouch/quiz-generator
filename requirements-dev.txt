# requirements-dev.txt — what the quality gate needs, and nothing else.

# The unit suite mocks every heavy adapter (vector store, embedder, reranker,
# LLM clients), so all 267 tests, ruff and mypy run without torch, CUDA,
# chromadb or sentence-transformers. Verified: the full suite passes on
# exactly this list. That keeps CI at seconds instead of a multi-GB install.
#
# Runtime dependencies are pinned in requirements.lock.txt — that is what
# `make setup` and the Docker image install. This file is the CI gate only.
#
# Every package that also appears in requirements.lock.txt is pinned to the
# SAME version here. CI must exercise the versions production ships; when
# these drifted apart, CI installed fastapi 0.121.2 and pulled a starlette
# with a known advisory that the locked fastapi 0.141.1 does not have.
